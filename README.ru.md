# Yog Installer

Устанавливает, обновляет и удаляет всё, что нужно разработчику Yog, — так
же, как Visual Studio Installer делает это для Visual Studio.

- **Продукты**: Yog IDLE — установка, обновление, изменение,
  восстановление, удаление, запуск.
- **Рабочие нагрузки**: *Разработка модов* (Yog CLI, набор инструментов
  Rust и пять целевых платформ, которые несёт `.yog`, zig, cargo-zigbuild,
  JDK, SDK загрузчика) и *Разработка загрузчика* (исходный код загрузчика и
  JDK для каждой его версии Minecraft).
- **Отдельные компоненты** с актуальными версиями: релизы GitHub,
  crates.io, Adoptium, ziglang.org.
- **Совместимость**: `yog-release.json` релиза говорит, что ему нужно от
  остальных; несовместимый выбор останавливается до установки.
- **Сначала обновляет себя**, потом всё остальное; если установку прервали (сбой,
  отключение питания), при следующем запуске Installer предложит продолжить,
  а загрузки продолжатся с того места, где остановились.

Компоненты:

| Группа | Компоненты |
|---|---|
| Компиляторы, средства сборки и среды выполнения | Набор инструментов Rust, целевые платформы Rust, Zig, cargo-zigbuild, Yog CLI |
| Java | JDK 17, 21 и 25 (Minecraft 1.19.2–1.20.1, 1.21.1, 26.2) |
| SDK и библиотеки | SDK загрузчика Yog, отладочные символы рантайма Yog (для отладчика) |

Всё ставится в домашнюю папку Yog (`~/.yog` или `$YOG_HOME`) и
записывается в `~/.yog/components.ydata`, который читают `yog run` и Yog
IDLE. Собственные переопределения компьютера — своя копия загрузчика, свои
JDK, окружение видеокарты — лежат в `~/.yog/local.toml`; Installer его не
трогает.

## Структура

| Путь | Что |
|---|---|
| `catalog/catalog.toml` | Канал: продукты, рабочие нагрузки, компоненты и где каждый публикуется |
| `crates/yog-installer-core` | Движок: каталог, версии, обнаружение, выбор, совместимость, установка, самообновление |
| `src-tauri/` | Команды приложения поверх движка |
| `src/` | Окно (React на UI Substrate-Platform) |

Подробности — в [docs/design.md](docs/design.md).

## Сборка

Substrate-Platform и Yog-Mod-Loader лежат рядом с этим репозиторием.

```sh
npm install
npm run tauri dev      # окно с живой перезагрузкой
cargo test --workspace # движок (проверки сети: -- --ignored)
```
